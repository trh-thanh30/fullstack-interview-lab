# Card AI-002 — Context retrieval

**Status:** DONE


**Priority:** P0  
**Size:** M  
**Dependencies:** ING-004, AI-001

**Outcome:** Evaluator nhận đúng source context thay vì chỉ dựa vào kiến thức model.

**Tasks:**

- [x] Embed câu hỏi hoặc retrieval query.
- [x] Filter chunk theo technology, source status và version.
- [x] Lấy top-k chunks và loại kết quả dưới similarity threshold.
- [x] Gắn source IDs vào evaluation input/output.

**Acceptance criteria:**

- [x] Câu React không retrieve tài liệu Docker nếu không liên quan.
- [x] Khi không đủ context, evaluator phải biểu thị uncertainty.
- [x] Có test dataset nhỏ để kiểm tra retrieval regression.

## Implementation notes

- Query embedding dùng cùng `GEMINI_EMBEDDING_MODEL` với source chunks; SQL cosine search chỉ đọc source `processed`, đúng topic, technology và embedding model hiện hành.
- `AI_RETRIEVAL_TOP_K` và `AI_RETRIEVAL_SIMILARITY_THRESHOLD` điều khiển top-k/threshold mà không cần sửa code.
- Khi không có chunk đạt threshold, evaluator xóa `incorrectClaims` và bắt buộc ghi uncertainty thay vì kết luận claim sai.
- Regression test xác nhận scope technology được truyền xuống repository và kết quả dưới threshold bị loại.
