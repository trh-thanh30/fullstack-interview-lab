## Implementation notes

- `src/ai/` cung cấp provider interface độc lập với SDK; adapter Gemini dùng Vercel AI SDK `streamText` + `Output.object` với Google Structured Outputs.
- Model, embedding model, retrieval threshold/top-k và token cost rates đều lấy từ environment. Request có timeout 45 giây và tối đa một retry.
- `ai_calls` chỉ lưu metadata vận hành, usage và mã lỗi đã chuẩn hóa; không lưu prompt, answer, API key hay raw provider error.
- Answer attempt được persist trước AI call. Timeout/refusal/provider error trả về retry path và không làm mất answer/session.
