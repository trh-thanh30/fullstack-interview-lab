## Implementation notes

- `/essay` liệt kê short-answer đã publish và recent sessions; `/essay/session/[id]` là private workspace có autosave debounce 700 ms.
- UI chỉ stream các trạng thái retrieval/rubric/validation trong lúc Server Action pending; structured JSON và raw provider error không được gửi ra client.
- Mỗi submit tạo answer attempt mới trước khi chấm. Retry evaluation dùng answer đã lưu; hai attempt gần nhất được đặt cạnh nhau để so score và nội dung.
- Score breakdown, strengths, missing points, incorrect claims, uncertainty, suggested answer, follow-up và source count đều hiển thị responsive.
