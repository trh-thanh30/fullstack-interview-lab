## Implementation notes

- Session snapshot giữ prompt, explanation, topic, choices, answer key và source metadata; chỉnh question bank không làm đổi session đang chạy hoặc result cũ.
- `current_position`, `state`, `asked_at`, `started_at` và `completed_at` được persist để reload/resume chính xác.
- Answer attempt số 1 có unique constraint; server re-read ownership, current position và choice membership trước mọi mutation.
- Migration `0005_minor_human_cannonball.sql` backfill snapshot an toàn cho session cũ trước khi đặt cột topic thành `NOT NULL`.
