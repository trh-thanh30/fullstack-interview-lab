## Implementation notes

- Auth.js dùng GitHub OAuth và JWT session; user hợp lệ được upsert vào bảng `users` khi đăng nhập.
- Allowlist chuẩn hóa chữ hoa/thường và chỉ chấp nhận email khớp hoàn toàn; cấu hình trống sẽ từ chối mọi tài khoản.
- Next.js Proxy thực hiện redirect sớm cho page route; `getAuthenticatedUser`/`requireAuthenticatedUser` là lớp kiểm tra quyền ở server.
- `/api/me` tự trả `401` khi không có quyền và sign-out Server Action gọi lại DAL trước khi thực thi.
- Sign-in, access-denied và user/sign-out state hỗ trợ responsive, keyboard và screen-reader label.
- Tài liệu cấu hình và threat boundaries: [`AUTHENTICATION.md`](../../system-design/AUTHENTICATION.md).
