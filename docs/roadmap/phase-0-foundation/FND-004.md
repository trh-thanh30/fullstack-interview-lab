## Implementation notes

- Workflow `.github/workflows/ci.yml` chạy trên Node.js 22 và pnpm được pin theo project.
- Mỗi quality command là một step riêng; bất kỳ step nào trả exit code khác `0` đều dừng job.
- Next.js build cache được lưu theo lockfile và source hash.
- CI không được cấp `DATABASE_URL` và có guard fail-fast nếu biến này xuất hiện trên runner.
- `vercel.json` cố định frozen install và production build command.
- Chiến lược secret/database theo môi trường nằm tại [`ENVIRONMENTS.md`](../../deployment/ENVIRONMENTS.md).
- Quy trình deploy, smoke test và rollback nằm tại [`PRODUCTION_CHECKLIST.md`](../../deployment/PRODUCTION_CHECKLIST.md).
