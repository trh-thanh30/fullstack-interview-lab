## Implementation notes

- `/review` là question bank với filter category, technology, level, type và lifecycle status; query chỉ chấp nhận enum/UUID hợp lệ.
- `/review/new` và `/review/[id]/edit` dùng chung editor responsive gồm nội dung, choices/rubric, taxonomy, provenance và practice preview.
- Server Actions kiểm tra authentication ở từng mutation rồi parse toàn bộ `FormData` bằng Zod; validation không phụ thuộc client UI.
- MCQ hỗ trợ tối đa sáu lựa chọn và đúng một đáp án. Short answer, deep dive và system design dùng rubric bốn dimension có tổng weight 100.
- `is_manual` biểu diễn provenance rõ ràng. Published question phải có source chunk hoặc bật manual.
- Create/update dùng Neon batch. Update tăng question version, thay choices/taxonomy/source links và append rubric version mới.
- Archive chỉ chuyển status sang `archived`; không có hard-delete action hoặc route.
