## Implementation notes

- `/review/generate` cho phép chọn loại câu hỏi và từ 1 đến 5 source chunks đã được normalize/classify.
- OpenAI Responses API trả Structured Outputs qua Zod; output sai schema hoặc sai invariant theo loại câu hỏi được retry tối đa hai lần.
- Service domain tự ép `status = draft` và `isManual = false`; provider không nhận status nên không có đường publish trực tiếp.
- `question_generation_runs` lưu response ID, model, prompt version và token usage; `question_sources` giữ nguồn của draft.
- API key và model lấy từ `OPENAI_API_KEY` và `OPENAI_QUESTION_MODEL`. Nội dung provider không được lưu tại OpenAI (`store: false`).
