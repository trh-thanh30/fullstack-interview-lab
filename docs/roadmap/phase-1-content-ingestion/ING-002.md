## Implementation notes

- Allowlist gồm năm directory JavaScript, React, Node.js, NestJS và Docker; tổng cộng 8 Markdown.
- Parser hỗ trợ ATX/Setext headings, paragraph, ordered/unordered list, fenced code và inline/reference image.
- Chunk content giữ nguyên raw Markdown; metadata lưu breadcrumb, heading level, line range, block counts và image references.
- Heading bên trong code fence không tạo section mới. Hash trong tên như `C#` không bị hiểu nhầm là closing marker.
- Exact duplicate section trong cùng source được loại trước khi insert để không vi phạm checksum uniqueness.
- Neon batch thay chunks và cập nhật source atomically. Import thành công xóa metadata lỗi cũ.
- Batch result giữ lỗi theo từng path và tiếp tục xử lý file kế tiếp.
